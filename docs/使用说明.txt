DeepSeek 记忆版 Android 客户端 v1.4 使用说明
================================================

一、安装
------------------------------------------------
1. 下载 DeepSeek-Memory-v1.4-release.apk。
2. 在手机上点开 APK；如果提示“未知来源 / 外部来源应用”，允许本次安装。
3. 本版更换了签名证书：如果你装过 v1.3 或更早版本，需要先卸载旧版再安装本版。
   卸载会清空本机的对话、长期记忆和 API Key，重要对话请先在旧版里导出备份。

二、从零开始配置 API Key
------------------------------------------------
1. DeepSeek 官网：https://www.deepseek.com
   开放平台（申请 API Key 的地方）：https://platform.deepseek.com
2. 用手机号 / 邮箱 / 微信注册并登录开放平台。
3. 打开 API keys 页面：https://platform.deepseek.com/api_keys
4. 点“创建 API key”，名称随意填；创建后复制以 sk- 开头的一串字符。
   注意：完整 Key 只显示这一次，请立刻保存好。
5. 确认账户有余额：https://platform.deepseek.com/top_up
   DeepSeek API 按量计费，余额为 0 时调用会报错。
6. 打开 App：
   - 首次打开：在引导页粘贴 API Key → 选择模型（推荐 DeepSeek Flash，便宜且支持图片；
     V4 Pro 理解更强，但成本约为 Flash 的 4 倍）→ 点“确认并进入”。
   - 已经进入过 App：左滑打开侧边栏 → 设置 → 数据管理 → “输入 API Key” → 粘贴后保存。
7. 回到首页新建对话，发送“你好”测试；能收到回复就说明配置成功。

常见报错：
- 401 / Authentication Fails：Key 填错、被删除或复制不完整，请重新创建。
- 402 / Insufficient Balance：余额不足，去充值页面充值。
- 429 / Rate Limit：请求太频繁，等一会儿再试。
- 网络错误：检查手机网络；App 直连 api.deepseek.com，不需要填任何代理地址。

三、附件上传限制
------------------------------------------------
- 每条消息最多 50 个文件；多次添加会累计，达到上限后需要先删掉一些。
- 图片：单个最大 64MB；支持 png、jpg、jpeg、webp、gif、bmp、svg、tiff、avif 等。
  不支持 HEIC / HEIF（iPhone 默认格式），请先转成 JPG。
- PDF、Word、PPT（pdf / doc / docx / ppt / pptx）：单个最大 64MB，会做版面识别。
- 其他文档、文本、代码、表格、电子书（txt、md、csv、xls、xlsx、epub 等）：
  单个最大 32MB。
- 同时最多上传 3 个文件，其余自动排队。
- 上传失败的附件不能随消息发送：可点重试图标重试，或点右上角 × 删除；
  格式不支持、超过大小限制的附件不能重试，只能删除。
- 一条消息必须包含文字或至少一个附件，不能发送完全空白的内容。

四、数据与备份
------------------------------------------------
- 所有对话、图片、长期记忆、API Key 都只保存在这台手机上，本项目没有服务器。
- 卸载 App 会全部清除；可在 设置 → 数据管理 → 导出所有历史对话 备份为 ZIP。
- 导出的 ZIP 包含对话和本地图片，不包含 API Key 和长期记忆。
- 本版签名证书已更换，后续升级请继续使用同一签名的 APK。

五、v1.4 更新内容
------------------------------------------------
- 修复：AI 回复的复制 / 朗读 / 重新生成按钮在所有消息上常显，不再只有最后一条可见。
- 修复：文档、图片附件上传成功后删除按钮常显，可以正常删除。
- 新增：编辑已发送消息时可以删除附件，支持文档、照片、图片等各类文件。
- 移除：输入框下方的“回答由 AI 生成，仅供参考”。
- 新增：设置 → 通用设置 里显示版本号 1.4。
